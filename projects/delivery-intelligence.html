The problem

A shared view for delivery investigation

Teams needed a common view of delivery performance and a way to investigate gaps across suppliers and shipments.

My contribution

I built the dashboard and data workflow, combining unstructured source data into a global delivery view with drill-down. I also added news-based exploration of possible disruption and a conversational agent for questions and report generation.

From input to outcome

How it works

The news feature helps users explore which suppliers or shipments may be exposed to an event. The conversational interface gives another way to work with the underlying delivery data and prepare reports.

  1. 01

    Bring the data together

    Unstructured source data is consolidated into a common view of global on-time delivery.

  2. 02

    Explore the gaps

    Teams drill into the delivery metrics to understand where supplier or shipment performance needs attention.

  3. 03

    Add external context

    News-based exploration helps users consider whether an event could affect particular suppliers or shipments.

  4. 04

    Ask and report

    A conversational agent supports questions about the data and helps users prepare reports for further discussion.

Behind the implementation

Design decisions

Connect the overview to investigation

Executives need the broad picture, while operational teams need to explore specific gaps. I built the dashboard to support both levels of review.

Use AI to help people work with the data

The agent sits alongside the dashboard as another way to investigate and report. The news feature adds context to a human review rather than making autonomous supply-chain decisions.

What changed

I demonstrated the system across teams, including to the CIO and sourcing leadership.

Project context

The news feature helps people investigate potential exposure. It is not an automated decision to reroute shipments or change suppliers.
