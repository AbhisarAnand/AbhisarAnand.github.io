Sync Assignments

Turning course emails into tasks

The problem

Assignment notices arrive in email, while the work is planned in a calendar or task manager. Copying the same deadlines into another system is repetitive and easy to get wrong.

My work

I built a Python workflow that reads course email notices, extracts assignments, and synchronizes them with Google Tasks and Todoist. The local version also includes a macOS launcher and notifications.

How it works

The workflow handles existing entries and daily-run checks rather than blindly adding a new task on every run. It reports new and existing assignments and sends a completion or error notification.

Scope

The workflow depends on the structure of course email notices and the connected task services.
