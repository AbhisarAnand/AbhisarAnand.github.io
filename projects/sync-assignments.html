Sync Assignments

Turning course emails into tasks

  • Python
  • Gmail API
  • Google Tasks
  • Todoist
  • macOS
View source on GitHub ↗See the workflow ↓

The problem

Less copying between email and tasks

Assignment notices arrive in email, while the work is planned in a calendar or task manager. Copying the same deadlines into another system is repetitive and easy to get wrong.

My contribution

I built a Python workflow that reads course email notices, extracts assignments, and synchronizes them with Google Tasks and Todoist. The local version also includes a macOS launcher and notifications.

From input to outcome

How it works

The workflow handles existing entries and daily-run checks rather than blindly adding a new task on every run. It reports new and existing assignments and sends a completion or error notification.

  1. 01

    Read course notices

    The workflow reads assignment notices from course emails instead of requiring manual entry in a separate task list.

  2. 02

    Extract the assignment

    Message parsing pulls out the assignment information and deadline used by the connected task services.

  3. 03

    Synchronize entries

    The integrations create or handle existing tasks in Google Tasks and Todoist, avoiding a new duplicate on every run.

  4. 04

    Report completion

    Daily-run checks and a macOS launcher support background use. Notifications report new or existing items and surface errors.

Behind the implementation

Design decisions

Treat repeat runs as normal

An automation that runs repeatedly has to account for what it has already done. Existing-entry handling and daily checks are part of the workflow rather than an afterthought.

Make background work visible

Notifications give the user a completion or error signal without asking them to keep a terminal open. The goal is a small utility that fits how coursework is already organized.

Project context

The workflow depends on the structure of course email notices and the connected task services.
