EchoPath

Exploring camera-based spatial audio cues

The problem

EchoPath explores whether a camera and headphones can communicate useful information about nearby objects. It translates visual observations into directional tones and spoken cues.

My work

I developed a local prototype that combines YOLO object detection, Depth Anything V2 depth estimates, object tracking, and spatial audio. The implementation can use OpenAL for spatialization, with a stereo audio fallback.

How it works

Raw detections can change from frame to frame. The tracking layer associates boxes over time and smooths estimated nearness before updating the sound. Spoken announcements use cooldowns so an object does not trigger the same message continuously.

Scope

This is a prototype, not a validated navigation aid. Monocular depth estimates are relative signals, not a guarantee of physical distance. A usable mobility system would need careful testing with its intended users, including failures and environmental changes.
