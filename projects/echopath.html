The problem

From visual observations to audio cues

EchoPath explores whether a camera and headphones can communicate useful information about nearby objects. It translates visual observations into directional tones and spoken cues.

My contribution

I developed a local prototype that combines YOLO object detection, Depth Anything V2 depth estimates, object tracking, and spatial audio. The implementation can use OpenAL for spatialization, with a stereo audio fallback.

From input to outcome

How it works

Raw detections can change from frame to frame. The tracking layer associates boxes over time and smooths estimated nearness before updating the sound. Spoken announcements use cooldowns so an object does not trigger the same message continuously.

  1. 01

    Observe the scene

    The camera feeds object detection and monocular depth estimation, producing boxes, object classes and relative nearness signals.

  2. 02

    Track across frames

    The tracking layer matches detections over time and smooths nearness estimates so audio does not jump with every frame.

  3. 03

    Choose the cues

    Object position informs direction, nearness changes the tone, and the voice layer selects objects for spoken announcements.

  4. 04

    Render the audio

    OpenAL supplies spatial audio, with a stereo fallback when it is unavailable. Cooldowns limit repetitive spoken cues.

Behind the implementation

Design decisions

Stability before more announcements

A detection that flickers is distracting when translated directly into sound. Tracking and smoothing turn frame-by-frame model output into more stable signals.

Use more than one audio path

Tones communicate changing direction and nearness, while speech can name an object. The implementation includes a stereo fallback so the prototype is not tied to a single audio backend.

Project context

This is a prototype, not a validated navigation aid. Monocular depth estimates are relative signals, not a guarantee of physical distance. A usable mobility system would need careful testing with its intended users, including failures and environmental changes.
