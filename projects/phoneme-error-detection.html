Phoneme Error Detection

Making pronunciation feedback easier to use

  • React
  • Python
  • FastAPI
  • Wav2Vec2
  • SQLite
See the workflow ↓

The problem

Feedback a learner can act on

A transcript can show which word a system recognized, but it does not explain which sound a learner should practice. This team project analyzes speech at the phoneme level and presents feedback in a practice interface.

My contribution

I contributed an adaptive pronunciation dashboard. The application lets users record a word, view analysis results, and revisit saved attempts. My contribution is part of a larger system with a FastAPI backend and a Wav2Vec2-based phoneme model.

From input to outcome

How it works

The backend compares predicted phonemes with a reference pronunciation and returns a structured response for the interface. Separate history endpoints let the product retain attempts instead of treating each recording as an isolated result.

  1. 01

    Choose a word

    The practice interface gives the learner a target word and a place to record an attempt.

  2. 02

    Analyze the audio

    The team’s speech pipeline predicts phonemes and compares them with a reference pronunciation.

  3. 03

    Inspect the feedback

    The dashboard presents the analysis so a learner can look beyond a full-word transcript and see the sounds being compared.

  4. 04

    Revisit attempts

    Saved practice history lets users return to earlier attempts instead of losing the context after each recording.

Behind the implementation

Design decisions

Connect feedback and practice

My dashboard contribution focused on the loop between making an attempt, understanding the result and deciding what to practice next. The interface needed to make the analysis usable.

Preserve the learning history

History endpoints and stored attempts connect individual recordings into a practice workflow. This supports revisiting performance without making an unmeasured claim about learning outcomes.

Project context

This was a team-built application. My contribution was the adaptive dashboard and practice workflow; the speech model was part of the broader team project.
