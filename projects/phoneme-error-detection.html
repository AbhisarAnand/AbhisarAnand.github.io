Dashboard contributor on a team project

Phoneme Error Detection

Making pronunciation feedback easier to use

The problem

A transcript can show which word a system recognized, but it does not explain which sound a learner should practice. This team project analyzes speech at the phoneme level and presents feedback in a practice interface.

My work

I contributed an adaptive pronunciation dashboard. The application lets users record a word, view analysis results, and revisit saved attempts. My contribution is part of a larger system with a FastAPI backend and a Wav2Vec2-based phoneme model.

How it works

The backend compares predicted phonemes with a reference pronunciation and returns a structured response for the interface. Separate history endpoints let the product retain attempts instead of treating each recording as an isolated result.

Scope

This was a team-built application. My contribution was the adaptive dashboard and practice workflow; the speech model was part of the broader team project.
