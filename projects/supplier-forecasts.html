Supplier forecast automation

Generate the workbooks, then make review straightforward

  • Python
  • Excel
  • Outlook
  • Workflow automation
See the workflow ↓

The problem

Monthly forecasts with a review step

Preparing and validating individual supplier forecasts could take two to three weeks. A readiness assessment also surfaced gaps in regular forecast communication.

My contribution

I built a tool that takes the supplier list and source data, generates each supplier’s Excel forecast in horizontal and vertical layouts, and prepares Outlook drafts with the right recipients and copied contacts.

From input to outcome

How it works

Generation and sending are separate steps. The tool prepares the files and drafts; people validate the output before sending it. That keeps the monthly communication process reviewable.

  1. 01

    Select suppliers

    A supplier list drives the run, alongside the source data and intended recipients.

  2. 02

    Build the workbooks

    The tool produces a supplier-specific Excel forecast in horizontal and vertical layouts.

  3. 03

    Prepare the communication

    Outlook drafts include the intended recipients and copied contacts, alongside the generated forecast files.

  4. 04

    Validate and send

    The team checks the output before sending. File generation is automated; the review remains an explicit part of the monthly process.

Behind the implementation

Design decisions

Automate the preparation together

Generating a workbook alone would leave the communication work behind. Preparing both files and drafts reduces repeated setup across suppliers.

Keep a person at the review step

The tool supports the team’s existing validation responsibility. Under a minute refers to generation; the complete workflow includes a few hours of review and subsequent sending.

What changed

Workbook generation takes under a minute, followed by a few hours of validation. The team adopted the workflow for monthly forecasts.

Project context

The full process includes human validation and sending. The tool is not described as sending forecasts autonomously.
